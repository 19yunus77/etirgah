# Ətirnamə — заметки по проекту (сводка сессии)

Состояние на 2026-11-16. Проект приостановлен владельцем; этот файл нужен, чтобы продолжить с того же места.

## Что это
Онлайн-магазин парфюмерных масел на разлив (продажа на граммы, физический товар, ~1400 позиций).
Продажи через Instagram **@etirname**, заказы через WhatsApp. Владелец — Юнус (Баку), общается по-русски.
Предпочтение: в пошаговых инструкциях по приложениям объяснения на русском, названия меню и кнопок на английском (интерфейс устройств английский).

## Название
- Сначала было «Ətirgah», но @etirgah и @etirgah.parfum заняты в Instagram → переименовали в **Ətirnamə** (@etirname свободен, профиль создан).
- Репозиторий и адрес сайта пока содержат старое имя: https://19yunus77.github.io/etirgah/
- Фирменный стиль: песочный/терракотовый (вариант C), логотип — книга + капля, надпись «Ətirnamə» шрифтом Noto Serif Display italic, второй шрифт Inter.
- Аватар Instagram: версия с надписью. Версия без текста: `brand/etirname_avatar_1080.png` (в репозиторий не входит, .png в .gitignore).

## Что сделано
1. **Каталог в Excel.** Все товары из склада (Anbar.xlsx), названия в порядке «бренд + название», розничные цены за грамм, заметки (верх/сердце/база) и описания на AZ/RU/EN. Файлы Excel в репозиторий не кладутся (.gitignore), лежат в рабочей среде сессии: Anbar_perakende.xlsx, Anbar_tesvir.xlsx.
2. **Сайт.** Один файл `index.html` (данные внутри), хостинг GitHub Pages, ветка main. Корзина → готовый текст заказа → ссылка wa.me на WhatsApp магазина либо кнопка «копировать». Языки AZ/RU/EN. Корзина в localStorage (`eg_cart2`), язык `eg_lang`.
3. **Настройки магазина** в `config.js`: номер WhatsApp `994553602525`, граммовка по умолчанию 10. Сменить номер = поправить одну строку и закоммитить.
4. **Instagram-профиль @etirname:** бизнес-аккаунт, кнопка Contact, био, аватар. Ссылку на сайт в био намеренно не ставили до покупки домена.

## Правила данных
- **Розничная цена за грамм** из оптовой: 0.15 и 0.2 → 0.6; 0.3 → 1; 0.5 и 0.7 → 2; от 1 до 1.5 и всё между → 3; выше 1.5 → 5. Флакон и база не оплачиваются; клиент сам называет количество граммов; цена = граммы × цена за грамм.
- Исходно брали остаток более 3000 г, затем решили включить все товары (вдруг завезут). Категорию «Hədiyyəli qutular» убрали.
- **Скрытые позиции** (41 шт.): в собственном названии (без бренда) есть `*` или скобки с буквами после пробела, например « (A)», « (T)». «Generation(s)» остаётся, это часть названия.
- Сейчас на сайте 1364 товара, 858 уникальных описаний.
- Перевод-глоссарий: сирень = yasəmən, жасмин = jasmin (не путать), водяной жасмин = su jasmini, дыня = yemiş, клюква = mərcanı / quşüzümü.
- Строки с особыми случаями (жёлтые): Avon Far Away и CK Secret Obsession (цена 0), Molecule 02 Escentric (4) и Oriflame Lucia (1) — нестандартная оптовая цена.

## Как пересобрать сайт
```
cd tools
python3 make_site.py /путь/к/Anbar_tesvir.xlsx   # создаёт ../index.html
```
Скрипты в `tools/`: `make_site.py` (сборка сайта), `shop_template.html` (шаблон страницы, `__DATA__` подставляется), `desc_data.py` (глоссарий и описания вручную), `parse.py` + `bulk1–6.txt` (данные ароматов вида `name|family|top|heart|base|season`), `build.py` (Anbar_perakende → Anbar_tesvir). Нужны Python, pandas, openpyxl.

## Что не доделано
- **365 видимых позиций без нот/описаний** (статус «Yoxlamaq»): в основном Molecule, «Arabic», Tiziana Terenzi, Sospiro, остаток Ajmal, Boadicea, Montale, Shaik, Avon, Oriflame. Владелец сам отметит самые ходовые, начинать с них.
- Ноты для известных брендов написаны по памяти, не сверены с источником; спорные азербайджанские термины («mavi lalə»/«lalə», «quru ot») проверить у носителя.
- **Домен:** узнать цену etirname.az у местного регистратора или взять etirname.com. После покупки: файл CNAME + DNS-записи для GitHub Pages, затем вписать ссылку в Instagram. Переименовать репозиторий (etirgah → etirname) лучше вместе с этим.
- **Посты в Instagram:** владелец пришлёт 10–15 фото флаконов/витрины; сделать шаблоны в стиле Ətirnamə с подписями AZ/RU. Реклама позже.
- **Telegram-бот с ИИ-консультантом:** нужен бот в BotFather, ключ Claude API, сервер (Cloudflare Workers бесплатно или VPS от ~$5/мес). Делать после домена.

## Расходы
- Бесплатно: GitHub Pages, код сайта, профиль Instagram, приём заказов через WhatsApp, шрифты.
- Платно: домен (.com около $10–15 в год, цену .az уточнить), Claude API для бота (по факту использования), сервер для бота (можно бесплатно на Cloudflare Workers), реклама (бюджет любой).
- Бизнесовые расходы: флаконы, упаковка, доставка, комиссия банка при подключении онлайн-оплаты (пока оплата вручную).
